# Meta-Analysis: When and How (YLNC)

Slides, a worked example and R scripts for a teaching session on meta-analysis, built with Quarto, the tidyverse and metafor.

**Website:** https://drgurpreet.github.io/meta_analysis_YLNC2026/

- `slides/meta_analysis_merged.qmd`: session deck (rendered `.html` alongside)
- `slides/meta_analysis_handson.R`: hands-on script
- `worked_example/`: worked example (`.qmd`, `.R`, rendered `.html`)

To update the site: re-render a `.qmd` in RStudio/Positron, copy the new `.html` here, commit and push.
